# 🍫 Belohnungsjournal – Streamlit v2

Neu in v2:
- Szenario-Shortcuts
- automatische Vorbelegung von Ergebnis, Auslöser und Strategie
- anschließende manuelle Anpassung möglich
- Szenario-Auswertung im Dashboard

## Lokal starten

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Auf Streamlit Community Cloud veröffentlichen

1. Neues GitHub-Repository erstellen.
2. `app.py` und `requirements.txt` hochladen.
3. Auf `share.streamlit.io` eine neue App anlegen.
4. `app.py` als Startdatei auswählen.
